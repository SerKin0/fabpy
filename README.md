# **FabPy**

Библиотека на Python для вычисления и оформления погрешностей в LaTeX в физических лабораторных работах, основанная на библиотеке SymPy.


## **Использование**
### Создание переменной 

После получения эксперементальных данных и занесения их в Python, например в список `list`, можем создать объект переменной, в которой и будут производиться вычисления погрешностей:
```Python
# Импортирование класса Values для хранения и обработки данных
from fabpy import Values

# Список эксперементальных данных
data_t = [10.5, 10.7, 10.6]
data_v = [1.2, 1.4, 1.0]
# Создание переменной времени с соответсующими данными
# Полная версия:
t = Values(
    name='t', values=data_t, error=None, unit=r'с',
    roundoff=1, rounded=True, float_point=',', alpha=0.95, delta=0.1
)
# Краткая версия:
v = Values(
    name='v', values=data_v, unit=r'\frac{м}{с}', delta=0.1
)
```

Класс `Values` имеет следующие параметры:
- `name` Имя переменной. Будет использоваться в формулах (допускается оформление LaTeX);
- `values` Значения переменной. Допускатеся количество значений $1 \leqslant n$ и может вводится как в `list|tuple`, так и `float|int`;
- `error` Асболютная погрешность значения. Класс способен вычислять gjuhtiyjcnm самостоятельно, но в некоторых случаях требуются конкретные значения, которое можно установить в этом параметре;
- `unit` Единица измерения. На данный момент представлена как строка, оформляемая в стиле LaTeX.
- `roundoff` Количество цифр после плавающей точки (запятой);
- `rounded` Округлять значение при подстановке в формулу и получения результата;
- `float_point` Символ плавающей точки;
- `alpha` Коэффициент доверия, используемый в вычислении случаной погрешности;
- `delta` Погрешность измерений прибора измерения;



### Погрешности величин

После получения экспериментальных данных из лабораторной работы нужно оценить их погрешность. Для этого нужно вычислить четыре значения по формулам: среднеквадратичного отклоненого, случайной и приборной погрешностей:
$$S_t = \sqrt{\frac{\sum_{i=1}^n (\overline{t} - t_i)^2}{n}}$$
$$\Delta t_\text{сл} = t_{\alpha, n} \cdot S_t \qquad \Delta t_\text{пр} = t_{\infty, n} \cdot \frac{\delta_t}{3}$$
$$\Delta t = \sqrt{t_\text{сл}^2 + t_\text{пр}^2}$$

Для вычисления этих формул нам необходимо знать следующие данные:
- `values` Эксперементальные данные;
- `alpha` Коэффициент доверия для получения коэффициента Стьюдента;
- `delta` Погрешность измерений прибора измерения;



### Среднеквадратичное отклонение

Статистическая характеристика распределения случайной величины, показывающая среднюю степень разброса значений относительно математического ожидания. 

$$S_t = \sqrt{\frac{\sum_{i=1}^n (\overline{t} - t_i)^2}{n}}$$

Расмотрим на примере:
```Python
from fabpy import Values

# Список эксперементальных данных
data_t = [10.5, 10.7, 10.6]

# Создание переменной времени с соответсующими данными
t = Values(name='t', values=data_t, unit=r'с', delta=0.1)


```

### **Вывод формул в $\LaTeX$**

Для получения формул вычисления погрешностей используется функция ```.latex()```, которая имеет четыре параметра:
$$\underbrace{\Delta t}_\text{name} = \underbrace{\sqrt{\Delta { t }_{ \text{пр} }^{2} + \Delta { t }_{ \text{сл} }^{2}}}_\text{general} = \underbrace{\sqrt{\left(0,1~\mathrm{\text{с}}\right)^{2} + \left(0,3~\mathrm{\text{с}}\right)^{2}}}_\text{values} = \underbrace{0,3~\mathrm{\text{с}}}_\text{result}$$

- `latex_name` Имя переменной с необходимыми обозначениями (прим. если это погрешность, то добавляется символ $\Delta$);
- `latex_general` Общая формула, в которую в последствии будут вводиться данные;
- `latex_values` Формула, с подставленными значениями;
- `latex_result` Результат вычислений с подставленной единицей измерения;

Каждый из этих элементов формулы можно убрать или оставить, по умолчанию установлено выводить все фрагменты формулы. Кастомизировать их можно, изменяя следующие параметры:
```Python
from fabpy import Values

# Список эксперементальных данных
data_t = [10.5, 10.7, 10.6]

# Создание переменной времени с соответсующими данными
t = Values(name='t', values=data_t, unit=r'с', delta=0.1)

# Полная формула
# Выводим без фрагмента общей формулы (general)
print(t.absolute_error.latex(
    print_name = True,
    print_general = False,
    print_values = True,
    print_result = True)
)

# Краткая форма
# Выводим только название переменной и ее значение
print(t.absolute_error.latex(
    print_general = False,
    print_values = False)
)
```
**Вывод:**
$$ 1)~\Delta \, { t } = \sqrt{ ({ 0,2 } \, \mathrm{ с })^2 + ({ 0,1 } \, \mathrm{ с })^2 } = 0,3 \, \mathrm{ с } $$
$$ 2)~\Delta \, { t } = 0,3 \, \mathrm{ с } $$

### **Примичание!**

Каждое значение погрешности можно задать произвольно, если это необходимо для расчетов. В качестве примера, рассмотрим случай изменения значения случаной погрешности.
```Python
from fabpy import Values

# Список эксперементальных данных
data_t = [10.5, 10.7, 10.6]
# Создание переменной времени с соответсующими данными

t = Values(name='t', values=data_t, unit=r'с', delta=0.1)

# Получаем результаты встроенного вычисления 
print(t.random.latex())
print(t.absolute.latex())

# Производим изменение значения случаной погрешности
t.random = 0.4

# Обновленные формулы
print(t.random.latex())
print(t.absolute.latex())
```
**Вывод:**
$$ \Delta { t }_{ \text{сл} } = S_{ t } t_{ 0.95,~n } = 0,1~\mathrm{\text{с}} \cdot 3,18 = 0,3~\mathrm{\text{с}} $$
$$ \Delta t = \sqrt{\Delta { t }_{ \text{пр} }^{2} + \Delta { t }_{ \text{сл} }^{2}} = \sqrt{\left(0,1~\mathrm{\text{с}}\right)^{2} + \left(0,3~\mathrm{\text{с}}\right)^{2}} = 0,3~\mathrm{\text{с}} $$
$$ \Delta t_\text{ сл } = 10.0 = 10,0 = 10,0~\mathrm{\text{с}} $$
$$ \Delta t = \sqrt{\Delta t_\text{ сл }^{2} + \Delta { t }_{ \text{пр} }^{2}} = \sqrt{\left(0,1~\mathrm{\text{с}}\right)^{2} + \left(10,0~\mathrm{\text{с}}\right)^{2}} = 10,0~\mathrm{\text{с}} $$
